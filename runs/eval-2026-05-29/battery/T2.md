# Tier 2 — the unpublished corpus

**Status: authoring started 2026-07-27. Never published, by design.**

Q01–Q56 is frozen and 15 of its tasks ship publicly (`HELDOUT-SPLIT.md`). Tier 2 is the
successor instrument: **authored to stay private forever**, so it remains a valid discriminator
even after the public sample is indexed, scraped, and trained on.

## Why tier 2 exists

Q56 is saturating **at the top of its range**: the crowned model scores 55/56 and the runner-up
54/56. It is *not* saturated in general — across 14 benchmarked configurations only 7 of 56 tasks
are never failed by anyone. So tier 2 is not a rescue. It is headroom above 50/56.

⚠️ **The wrong lever is difficulty.** Measured evidence: the hardening batch that added
*difficulty* to Q50 moved the champion 46 → 47, i.e. nothing. Meanwhile the crown holder swept
the genuinely hard tail (Q53–Q56) while its single most reliable failure was a trivial
empty-range guard. **Difficulty and discrimination are close to orthogonal on this corpus.**

## The four axes — where the headroom actually is

Each tier-2 task must be justified by at least one, and its ID records which.

1. **Trap density.** Most Q56 tasks carry one hidden trap. A task with 3–4 *independent* traps,
   all of which must be handled simultaneously, multiplies discrimination while each individual
   trap stays fair. Partial credit does not exist, so density compounds.

2. **★ Agent mechanics.** The corpus barely measures this and it produced the two most
   distinctive findings of the whole sweep. Four models independently lost tasks to *mechanical*
   failures, not reasoning: `gpt-oss-20b` lost 3 of 16 to unparseable output (a bare top-level
   `return`; literal `\n` escapes written into a `.mjs`), `north-mini` lost 2 (unterminated
   triple-quoted string; Rust `E0425`), `granite` likewise, and `devstral` reached for an
   unvendored crate in an offline sandbox. Grade: multi-file coherence, obeying existing
   conventions, and **adding no dependencies**.

3. **Regression avoidance.** Q56's hidden tests almost all check only the NEW behaviour. A task
   whose obvious fix silently breaks a working feature is brutally discriminating and completely
   fair — the hidden tests simply assert the old behaviour still holds.

4. **Context pressure.** Every Q56 fixture is small; ctx 32768 is never stressed and we never
   test whether a model can *find* the relevant code before changing it. Tier-2 fixtures may be
   large, with the target buried and the prompt describing a symptom rather than a location.

## Rules (non-negotiable)

- ★★ **Author from this taxonomy, NEVER from a model's failure list.** The moment tasks exist
  because the champion fails them, the benchmark measures "things that beat gemma" rather than
  code quality. No tier-2 task may be motivated by an observed failure.
- **Every task passes `gate_t2.sh`**: the verifier must FAIL on the untouched fixture and PASS on
  fixture + reference solution. Same test-first discipline as Q56.
- **Fair to a reviewer.** Traps are unstated-but-implied, never secret gotchas. A competent human
  reviewer reading the prompt should agree the hidden test is reasonable.
- **Hidden verification only.** Pass/fail is the compiler and the test runner. No transcript
  grepping, no LLM judge. Deterministic ground truth may be lowered by a model, never raised.
- **Toolchain scope** is unchanged: rust / python / js / ts / shell. Nothing else builds on this
  box, and a task that can't be built can't be gated.
- **Held constants** are unchanged: ctx 32768, KV q8_0, parallel 1, recorded per run.

## Layout

Tier 2 shares the battery home so the whole harness works unmodified. IDs are `T01…` and the
task list is `manifest-t2.tsv`.

```
prompts/T<nn>.txt        what the model sees
fixtures/T<nn>/          copied to work/T<nn> — the model's workspace
verify/T<nn>.sh          injects hidden tests, builds/runs, prints RESULT: PASS|FAIL
refsol/T<nn>/            overlay that makes verify pass; gate-only, never seen by a model
manifest-t2.tsv          id, lang, axis, id, timeout
```

⚠️ **Publication is an ALLOWLIST, never a blocklist.** The public export ships exactly the 15
task IDs named in `HELDOUT-SPLIT.md`. Nothing is published by default, so a tier-2 task cannot
leak by being forgotten. `gate_q50.sh` with no arguments still globs `fixtures/Q*` only, so the
published corpus keeps its own independent gate.

Run tier 2 like any other manifest:

```
BATTERY_MANIFEST=$PWD/manifest-t2.tsv BATTERY_TAG=t2-<model> \
  CLAUDETTE_MODEL=<key> bash run_battery.sh
```

## Calibration target

Q56's champion baseline landed at 87.5%, which turned out too high to discriminate well at the
top. **Tier 2 should aim for the crown holder scoring 50–70%** — low enough to leave headroom
above the current ceiling, high enough that the tasks are clearly fair. Calibrate against
`gemma-4-26b-a4b-qat`, not against the old speed champion, since gemma defines the current
ceiling.

⚠️ Calibration is the ONE place a model's results may influence authoring, and only in
aggregate — "the batch is too easy / too hard". Never per-task.
