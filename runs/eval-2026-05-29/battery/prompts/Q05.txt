The `parse_kv` function in src/lib.rs parses "key=value" lines into a map, but it panics whenever a line is malformed. Change it to return `Result<HashMap<String, String>, String>` instead: `Ok(map)` on success, or `Err(message)` describing the problem if a line has no '='. Keys and values should be trimmed of surrounding whitespace. Callers pass whole config files, so make sure it handles them gracefully.
