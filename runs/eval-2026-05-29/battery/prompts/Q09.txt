Implement the two run-length-coding functions in src/lib.rs: `rle_encode` and `rle_decode`. A run of a character repeated n times is written as that character followed by the count — for example "aaabb" encodes to "a3b2". Decoding reverses it. The input to encode is lowercase letters. The two functions should round-trip any such input, and decode should correctly reverse whatever encode produces. There are tests showing the basic shape.
