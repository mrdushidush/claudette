The `flatten` function in solution.mjs is supposed to flatten a nested array by a given number of levels (default 1), but it ignores the depth argument entirely and always flattens all the way down. Fix it so it respects depth: flatten([1,[2,[3]]]) with the default depth returns [1, 2, [3]], depth 2 goes one level deeper, and a depth of Infinity flattens completely.
