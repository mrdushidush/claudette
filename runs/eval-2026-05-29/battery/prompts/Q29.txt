The `safeGet(obj, path, defaultValue)` function in solution.mjs reads a nested value from an object using a dot-separated path like "a.b.c". It's supposed to be "safe": if the path doesn't exist it should return the provided default instead of throwing. Right now it blows up with a TypeError as soon as it hits a missing or null intermediate value. Fix it so a missing path returns the default, values along the way that are null/undefined are handled gracefully, and genuinely-present falsy values (like 0 or false) are still returned. You can check the basics with `node test_basic.mjs`; keep it passing.
