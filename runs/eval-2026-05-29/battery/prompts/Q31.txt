Implement `groupBy(arr, keyFn)` in solution.mjs. It groups the elements of `arr` into an object keyed by the value that `keyFn` returns for each element — for example groupBy([1,2,3,4], n => n % 2 === 0 ? "even" : "odd") gives { odd: [1, 3], even: [2, 4] }. Items within each group should stay in the order they appeared in the input. You can check the basics with `node test_basic.mjs`; keep it passing.
