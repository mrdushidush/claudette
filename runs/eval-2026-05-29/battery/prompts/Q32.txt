The `intersection` function in solution.mjs returns the unique elements of array `a` that also appear in array `b`, in the order they first appear in `a`. It works but it's quadratic — on large arrays it becomes very slow because of the nested scanning. Make it run in roughly linear time while keeping the exact same behavior (order of `a`, no duplicates). You can check the basics with `node test_basic.mjs`; keep it passing.
