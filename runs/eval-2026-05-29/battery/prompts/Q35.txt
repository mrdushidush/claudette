The `parseQueryString` function in solution.ts parses a URL query string like "a=1&b=2" into an object. It's too naive. Make it handle real query strings: a repeated key like "a=1&a=2" should collect its values into an array (["1","2"]); percent-encoding (%20) and "+" should be decoded to spaces and characters; a leading "?" should be ignored; a bare key with no "=" should map to an empty string; and an empty input should give an empty object.
