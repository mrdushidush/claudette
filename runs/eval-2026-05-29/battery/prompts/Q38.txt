The `safeJsonParse` function in solution.ts is meant to be a safe wrapper around JSON.parse that never throws: on success it returns { ok: true, value }, and on invalid input it should return { ok: false, error } with an error message string. Right now it doesn't actually catch anything, so bad JSON throws straight through. Fix it so invalid or empty input yields an { ok: false, error } result instead of throwing.
