The script solution.sh is supposed to strip comment lines and blank lines out of stdin, printing the rest unchanged. A comment line is one whose first non-whitespace character is '#' (so it may be indented), and a blank line is one that is empty or only whitespace. Right now it only removes comments that start with '#' at the very first column, and it leaves blank and indented-comment lines in. Fix it. Note that a '#' appearing later in a line (like an inline comment after code) must NOT cause the line to be dropped. Run it like: bash solution.sh < input.txt
