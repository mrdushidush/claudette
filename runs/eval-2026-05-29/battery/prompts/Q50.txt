The script solution.sh takes a column number N as its argument and should print the Nth comma-separated field of each line of stdin (1-indexed). Right now it splits on spaces instead of commas, so it doesn't work on CSV. Fix it to split on commas. It should handle lines that have fewer than N fields (print an empty line for those), and empty fields (a value between two commas) should come through as empty. For example, printf 'a,b,c\n' | bash solution.sh 2 prints "b".
