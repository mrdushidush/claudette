Implement `compare_versions(a, b)` in src/lib.rs. It compares two dotted version strings and returns a std::cmp::Ordering. Components are compared NUMERICALLY, not as text — so "1.10.0" is greater than "1.2.0" (10 > 2), even though "10" sorts before "2" lexically. Versions with different numbers of components compare as if the shorter one is padded with trailing zeros, so "1.2" equals "1.2.0". There's a test showing the basic shape. Handle versions of any length.
