The small library in src/ parses duration strings like `90s` and `5m` and formats durations for display. It currently understands only seconds and minutes. Add support for hours using the `h` suffix, so that `1h`, `2h30m` and `1h30m45s` parse correctly, and so the formatter prints an hours component when a duration is an hour or longer. Anything the library advertises as supported should stay accurate. This project is offline: it must not gain any new dependencies.
